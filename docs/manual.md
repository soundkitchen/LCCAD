# LCCAD 取扱説明書

macOS ネイティブのレザークラフト専用 CAD「LCCAD」の操作マニュアルです。現行バージョン(0.1.0)の実装に基づいて記述しています。

- 動作環境: macOS 14.0 (Sonoma) 以降
- 内部単位: ミリメートル (mm)。**現バージョンの表示単位は mm 固定**です(inch 切替は将来対応予定)

## 1. 起動と画面構成

アプリを起動すると、ファイル選択ダイアログは表示されず、すぐに新規キャンバスが開きます。ファイルの保存・読み込みは File メニューから行います。

画面は次の要素で構成されます:

| 領域 | 内容 |
|------|------|
| **メニューバー** | macOS システムメニューバー(File / Edit / View / Arrange / Draw / Stitch) |
| **ツールバー** | ウィンドウ上部。描画ツール 8 種 → 編集ツール 3 種(Offset / Trim / Bevel)→ Page ツール → ステッチ系ボタン(暖色)→ 右端に Undo / Redo |
| **左パネル** | Layers(レイヤー)/ Templates(テンプレート)の 2 タブ |
| **キャンバス** | 中央の作図領域。上端・左端にルーラー |
| **右パネル** | 選択中の図形のプロパティ(Properties)。Page ツール選択中はページ設定(Page Layout) |
| **ステータスバー** | 下端。カーソル座標、ページ数、単位、ズーム操作 |

ライト/ダークモード両対応です(切替は[環境設定](#13-環境設定))。

## 2. キャンバスの基本操作

### ズーム

- **マウスホイール** — カーソル位置を中心に拡大縮小
- **ステータスバーの − / ＋ ボタン**、または **⌘+ / ⌘−**
- **ステータスバーのズーム率フィールド** — 数値を直接入力(入力は 1〜1600%、実効ズームは約 17〜1600%)。Enter で確定
- **⌘0**(View ▸ Zoom to Fit)— 表示を 100% に戻し、原点をキャンバス中央に配置

### パン(表示の移動)

- **マウス中ボタンのドラッグ**で表示を移動します(トラックパッドの 2 本指スクロールはズームに割り当てられています)

### グリッド

ズームレベルに応じて粒度(0.1 / 0.2 / 0.5 / 1 / 2 / 5 / 10 mm …)が自動で切り替わります。**View ▸ Toggle Grid(⌥⌘G)** で表示/非表示を切替できます。

### スナップ

描画ツールでの作図はグリッドと図形の特徴点にスナップします。スナップ先は緑色のマーカーで表示されます:

| マーカー | スナップ先 |
|---------|-----------|
| ダイヤモンド | 端点 |
| 三角 | 中点 |
| 小さいドット | 線の 1/4・3/4 点、グリッド点 |
| クロスヘア | 中心(矩形・楕円・弧) |
| X | 交点(線分どうしのみ) |

- スナップの許容距離は約 8px(画面距離)
- **選択ツールのクリックはスナップしません**(グリッド外の部分も狙ってクリックできるようにするため)
- 非表示レイヤーの図形はスナップ候補になりません

### ルーラー

**View ▸ Toggle Ruler(⌘R)** で表示/非表示を切替。ズーム・パンに連動します。

## 3. 図形を描く

ツールバーまたは単キーショートカットでツールを選択します(ショートカットはキャンバスにフォーカスがあるときに有効)。**Select 以外のツールへ切り替えると選択は解除されます**(Select ツールへの切替では選択は保持されます)。作図中は **Escape** でキャンセルできます。

| ツール | キー | 操作方法 |
|--------|-----|---------|
| **Select** | V | 選択・移動・編集([4 章](#4-選択と編集)) |
| **Line** | L | 2 点クリック、またはドラッグ。プレビューに長さを表示 |
| **Rectangle** | R | ドラッグ。**Shift で正方形**に拘束。サイズをプレビュー表示 |
| **Ellipse** | E | ドラッグ。**Shift で正円**に拘束 |
| **Arc** | A | 3 クリック(始点 → 終点 → 膨らみ方向)。3 点目の位置で弧の向きと半径が決まる |
| **Bezier** | P | クリックで制御点を追加していき、**Enter または Escape で確定**(2 点以上必要) |
| **Text** | T | クリックで配置。内容・フォント等は右パネルで編集 |
| **Dimension** | D | 寸法線。3 クリック(始点 → 終点 → ラベル位置)。[10 章](#10-寸法線) |

線の描画色・線種(実線 / 破線 / 点線 / 一点鎖線)は右パネルの Stroke セクションで変更できます。**線幅は 0.1mm 固定**です(実寸印刷の精度を安定させるため変更できません)。

## 4. 選択と編集

Select ツール(V)での操作:

| 操作 | 動作 |
|------|------|
| クリック | 図形を選択(許容 5px)。スナップは働かない |
| Shift + クリック | 選択に追加 / 解除トグル |
| 空白部分のドラッグ | マーキー(矩形範囲)選択 |
| 選択図形のドラッグ | 一括移動。移動中は選択範囲の外接矩形の 4 角+中心の 5 点でスナップが評価される(図形側がグリッドや特徴点に乗る) |
| Delete | 選択図形を削除(紐づくステッチ穴も一緒に削除) |
| ⌘A / ⌘D | 全選択 / 選択解除 |

- ドラッグ中にカーソルがキャンバス端に達すると自動スクロールします
- **ベジェ曲線を単一選択**すると、アンカー(青四角)とハンドル(青丸)が表示され、ドラッグで編集できます。**Shift + ドラッグ**で対称ハンドルの連動を解除して片側だけ動かせます
- **Undo / Redo**: ⌘Z / ⇧⌘Z(ツールバー右端のボタンでも可)

## 5. プロパティパネル(右パネル)

選択内容に応じて表示が変わります:

- **Position** — X / Y 座標(編集可)
- **Size** — 幅 / 高さと回転角(表示のみ)
- **Stroke** — 線色(カラーピッカー)、線幅(0.1mm 固定表示)、線種(Solid / Dashed / Dotted / Dash-Dot)
- **Text 選択時** — 内容、フォント、サイズ(1〜200mm)、Bold / Italic、揃え、色
- **Arc 選択時** — 半径 R(mm)、開始角 S / 終了角 E(°)を直接編集可。中心角は表示のみ
- **Dimension 選択時** — 種類(Aligned / Horizontal / Vertical)、実測値(表示のみ)、オフセット、ラベル上書き
- **Stitch Settings** — 目打ちの種類と配置モード([9 章](#9-ステッチ目打ち穴の自動配置))
- **複数選択時** — 合成範囲の位置・サイズ、線設定の一括変更
- **Bevel ツール選択時** — 丸め半径(0.1〜100mm)
- **Page ツール選択中** — ページ設定([11 章](#11-ページレイアウトと実寸印刷))

## 6. 整列・複製・変形

### 整列と分布(Arrange メニュー)

2 個以上選択で整列(Align Left / Right / Top / Bottom / Center Horizontally / Center Vertically)、3 個以上で分布(Distribute Horizontally / Vertically)が使えます。

### 反転・反転コピー

| コマンド | ショートカット | 動作 |
|---------|--------------|------|
| Mirror Horizontally | ⇧⌘\| | 選択範囲の中心の縦軸で左右反転 |
| Mirror Vertically | ⇧⌘_ | 中心の横軸で上下反転 |
| Mirror Right (Copy) | ⌥⌘M | 右端を軸に反転コピー(原本の右隣に密着) |
| Mirror Down (Copy) | ⌃⌘M | 下端を軸に反転コピー |

左右対称の型紙は、半分だけ描いて Mirror Right (Copy) を使うと効率的です。

### 配列複製(Arrange ▸ Array... / ⌥⌘A)

選択図形を規則的に複製します:

- **Linear** — 個数(2〜500)と X / Y オフセット
- **Grid** — 行数 × 列数(各 1〜100)と行間・列間
- **Polar** — 個数(2〜100)、半径、開始角、展開角。「Rotate Items」で複製自体も回転

### グループ化

**⌘G** でグループ化、**⇧⌘G** で解除。ネスト可能です。グループを移動すると子図形のステッチ穴も追従します。

### Offset / Trim / Bevel(ツールバーの編集ツール)

| ツール | 操作 | 動作 |
|--------|------|------|
| **Offset** | 図形をクリック | 平行コピーを追加(距離は現在 3mm 固定)。矩形・楕円・弧は内側(中心側)へ、線・ベジェは図形の向きで決まる片側へ作られる(方向の指定は未実装)。線・矩形・楕円・弧・ベジェに対応 |
| **Trim** | 線をクリック | 他の図形との交点で分割し、**クリックした区間を削除**。線・弧・ベジェ・矩形・楕円に対応 |
| **Bevel** | 右パネルで半径を設定し、角をクリック | 線同士の角、または矩形の角を丸める(矩形は線 4 本+弧に分解される) |

複数の角をまとめて丸める場合は **Arrange ▸ Bevel...(⌥⌘B)** で、選択範囲内の検出された全角を一括処理できます(対象角数がプレビュー表示されます)。一括処理はベジェの角も対象です。なお矩形の扱いは単一クリックと異なり、図形を分解せず角丸矩形のまま丸められます。

## 7. レイヤー

左パネルの **Layers** タブで管理します。

- **＋** — レイヤーを追加(名前は自動で「Layer N」)
- **ゴミ箱** — アクティブレイヤーを削除(最後の 1 枚は削除不可)
- **↑ / ↓** — アクティブレイヤーの並べ替え
- **目のアイコン** — 表示 / 非表示の切替。非表示レイヤーは描画・スナップ・SVG エクスポートの対象外
- 行をクリックするとアクティブレイヤーが切り替わり、新規図形はアクティブレイヤーに描かれます

## 8. テンプレート

よく使うパーツ(図形の組)を保存して再利用できます。左パネルの **Templates** タブで管理します。テンプレートはドキュメントを跨いで使える共有ライブラリに保存されます。

### 保存

1. 保存したい図形を選択
2. Templates タブの「＋ 選択を保存」をクリック
3. 名前と保存形式を指定して「保存」
   - **平坦** — 配置時に個別の図形として展開される
   - **グループ** — 配置時に 1 つのグループとして扱われる

※ ステッチ穴はテンプレートに保存されません(図形のジオメトリのみ)。

### 配置

一覧の行をクリックすると配置モードになり、半透明のゴーストがカーソルに追従します。クリックで配置(スナップ有効)、**Escape でキャンセル**します。配置のたびに独立したコピーが作られます。

## 9. ステッチ(目打ち穴の自動配置)

レザークラフトの縫い穴(目打ち跡)を図形の輪郭に沿って自動配置します。ステッチ関連の UI は暖色(キャメル色)で表示されます。

### 目打ち(Pricking Iron)の設定

**Stitch ▸ Pricking Iron Settings...**(または右パネル Stitch Settings の歯車ボタン)で目打ちを管理します:

| 項目 | 内容 |
|------|------|
| Type | Diamond(菱目)/ French(ヨーロッパ目)/ Round(丸目)/ Flat(平目) |
| Pitch | 穴の間隔 (mm) |
| Teeth | 刃数 |
| Angle | 穴の傾き(丸目では効果なし) |
| Size | 穴の径/幅 (mm) |

新規ドキュメントには「Diamond 4mm」が登録されています。目打ちはドキュメントごとに保存されます。

### Auto Stitch(自動配置)

図形を選択して **Stitch ▸ Auto Stitch**(またはツールバーのグリッドアイコン)を実行すると、輪郭に沿って穴が配置されます。端点が一致する(0.1mm 以内)複数の開いた線・弧・曲線は 1 本の連続パスとして溶接されます。

配置ルールは図形の形状で決まります:

- **角のあるパス**(矩形など) — 各角に必ず穴を打ち、角と角の間を均等割り。モードは Even Count のみ有効(全角に穴を置いた上で指定個数に配分)で、Fixed / Variable / Hybrid は影響しません
- **閉じた滑らかなパス**(円・楕円) — 全周を均等割り(Even Count も有効)
- **開いた滑らかなパス** — 右パネルの Mode 設定が有効:

| Mode | 動作 |
|------|------|
| Fixed Pitch | 始点から目打ちのピッチどおりに配置(終端は余る) |
| Variable Pitch | 両端に穴が来るようピッチを微調整して均等化 |
| Even Count | ピッチを無視して指定個数ちょうどを配置(Count 欄で指定) |
| Hybrid | 始点からクリック指定位置まで厳密ピッチ、残りを均等化 |

**Hybrid モードの操作**: Auto Stitch 実行後、キャンバス上部に「クリックで固定→可変の切替点を指定 ・ Esc でキャンセル」というバナーが表示されます。パス上をなぞるとゴースト穴と切替点マーカーがプレビューされ、クリックで確定します。ピック操作の対象になるのは開いた滑らかなランのみで、角のあるパスや閉じたパスは Hybrid でも即座に確定します。複数のランをまとめて Auto Stitch した場合はランごとに 1 クリックずつ指定します(Escape で残りをキャンセル)。

配置済みのステッチ穴は**図形に紐づいて追従**します。図形を移動すれば穴も移動し、変形すれば再生成されます。図形を削除すると穴も消えます。

### Box Stitch(駒合わせ)

箱物の側面と底面のように、**2 つのパーツの穴数を揃えて**縫い合わせるための機能です。

1. パーツとなる 2 つの輪郭(2 ラン)を選択(選択がちょうど 2 ランに解決できるとメニュー/ボタンが有効になります)
2. **Stitch ▸ Box Stitch...** を開く
3. 目打ちと穴数ポリシーを選択:
   - **Larger** — 長い方のパーツに合わせる
   - **Smaller** — 短い方に合わせる
   - **Custom** — 個数を直接指定
4. シート表示中はキャンバスに両パーツの穴が半透明でライブプレビューされます
5. ピッチの乖離警告などを確認して **Apply**

適用後は両パーツとも Even Count モードで穴数が固定され、図形を編集しても個数が保たれます。

## 10. 寸法線

Dimension ツール(D)で採寸の注記を入れられます。

- **3 クリックで作成**: 始点 → 終点 → ラベル位置(3 点目の位置で寸法線のオフセットと向きが決まる)
- **種類**(右パネルの Type): Aligned(2 点間の実距離)/ Horizontal(水平成分)/ Vertical(垂直成分)
- **数値は自動計算**され、右パネルの Label 欄に入力すると任意のテキストで上書きできます(空欄に戻すと自動値)
- 数値ラベルは JIS 製図流に配置されます: 横向きの線は線の上、縦向きの線は 90° 回転して線の左(下から上に読む)
- 寸法線はエクスポート(SVG / DXF)・印刷にも出力されます

## 11. ページレイアウトと実寸印刷

LCCAD の印刷は常に**実寸(100%)**です。型紙をそのまま印刷して使えます。

### ページ配置(Page ツール)

ツールバーの **Page** ツールを選ぶと右パネルがページ設定(Page Layout)になります:

- **PAPER** — 用紙サイズ(A4 / A3 / B4 / Letter / Legal)、向き(Portrait / Landscape)、余白(0〜50mm)
- **PAGES** — キャンバスをクリックした位置にページ枠を追加。一覧の行をクリックでページを選択
- **POSITION**(ページ選択時に表示) — 選択中ページの X / Y 位置を数値で微調整
- **LAYOUT** — ページ間のオーバーラップ量(0〜50mm)、ページ枠の表示切替(**⇧⌘P** でも切替可)

選択中のページは、Page ツールが有効な状態で **Delete キー**を押すと削除できます。

**File ▸ Print...(⌘P)** で、配置したページがそれぞれ用紙 1 枚に実寸でマップされます。

ページを 1 枚も配置していない場合は、図面全体が自動でタイル分割されます(タイル間 10mm オーバーラップ+位置合わせマーク付き)。

### プリンターキャリブレーション

プリンターの機差(数 % の伸縮)を補正して寸法精度を高める機能です:

1. **File ▸ Print Calibration Page...** で校正ページを印刷(150mm の正方形が印刷されます)
2. 印刷された正方形の実寸を定規で測定
3. **Settings ▸ Printer Calibration ▸ Add Calibration...** でプリンターを選び、実測値(X / Y)を入力 → 補正倍率が自動計算されます(実測値は 100〜200mm の範囲で入力。範囲外はエラーになります)
4. 以後、そのプリンターでの印刷に補正が適用されます

キャリブレーション未設定のプリンターで印刷しようとすると警告が表示されます(そのまま印刷することも可能です)。

## 12. ファイル操作とエクスポート

### 保存と読み込み

| コマンド | ショートカット | 内容 |
|---------|--------------|------|
| File ▸ New | ⌘N | 新規ドキュメント |
| File ▸ Save | ⌘S | 上書き保存(初回は保存先を選択) |
| File ▸ Save As... | ⇧⌘S | 名前を付けて保存 |
| File ▸ Open... | ⌘O | `.lccad` ファイルを開く |

ファイル形式は `.lccad`(JSON ベースの独自形式)です。未保存の変更がある状態で New / Open / ウィンドウを閉じる / 終了しようとすると確認ダイアログが表示されます。タイトルバーのドットが未保存状態を示します。

### エクスポート

- **File ▸ Export ▸ SVG...(⇧⌘E)** — 表示中レイヤーをレイヤー構造付きで出力。ステッチ穴は円として含まれます。レーザーカッターやイラストソフトへの受け渡しに
- **File ▸ Export ▸ DXF...** — DXF R12 形式。線種(実線/破線/点線/一点鎖線)もラインタイプとして出力されます。CAD ソフトへの受け渡しに

いずれも座標は mm 単位で出力されます。

## 13. 環境設定

**LCCAD ▸ Settings...(⌘,)** で開きます。

- **General** — Color Mode(System / Light / Dark)。アプリの外観を切替
- **Printer Calibration** — プリンター校正値の一覧・追加・編集・削除([11 章](#11-ページレイアウトと実寸印刷))

## 15. 既知の制限

現バージョン(0.1.0)の主な制限事項です:

- **表示単位は mm 固定** — inch 切替の UI は未実装
- **図形のコピー&ペーストは未実装** — 複製には配列複製(⌥⌘A)、反転コピー、テンプレートを利用してください
- **Offset の距離は 3mm 固定** — 距離指定 UI は未実装
- **図形の回転操作は未実装** — 右パネルの回転角は表示のみ
- **レイヤーのロック・名前変更は未実装** — 表示/非表示のみ対応。レイヤー操作(追加・削除・並べ替え・表示切替)は Undo できません
- **矩形の角丸は Bevel ツールで** — 角丸半径を直接指定する UI はありません
- **用紙サイズの Custom は未対応** — 選択肢には表示されますが寸法入力 UI がなく、A4 として扱われます
- **Stitch Simulator は計画中** — メニュー・ツールバーに表示されますが現在は無効です
